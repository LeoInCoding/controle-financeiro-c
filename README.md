# Controle Financeiro em C

Projeto desenvolvido para praticar lógica de programação utilizando a linguagem C.

## Funcionalidades
- Definir orçamento mensal
- Registrar até 30 despesas
- Listar despesas cadastradas
- Visualizar total gasto, saldo restante, maior despesa e média de gastos
- Identificar quando o orçamento é ultrapassado

## Conceitos utilizados
- Estruturas condicionais (`if`, `else`, `switch`)
- Estruturas de repetição (`for`, `while`)
- Vetores
- Variáveis e operadores
- Entrada e saída de dados

## Como executar

Compile o arquivo `main.c` utilizando GCC:

gcc main.c -o main

Execute o programa no terminal.
